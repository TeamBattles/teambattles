Rainbow Six Siege is available in [Battles Strategy](https://teambattles.gg/strategy/editor) with
27 maps, 106 ordered blueprint levels, and a searchable catalog of 175 tokens. That includes 168
official operator, gadget, and ability tokens plus seven shared strategy markers.

<Warning>
	**Strategy only.** Rainbow Six Siege is not available for TeamBattles matches, challenges,
	leagues, ranks, rules, or matchmaking. You do not need to connect a Ubisoft account to draw a
	strategy.
</Warning>

Every map includes its ordered official blueprint images. Together, the catalog has 106 levels.
Use the level selector in the editor header to choose the blueprint shown by the current stage. A
stage without a saved choice uses that map's default level.

To keep a token visible through a route between blueprint levels, select it and use **Visible on levels** in
**Properties**. That setting follows the token across the complete strategy. See [Managing your
strategies](/strategy/managing-strategies#visible-on-levels) for the full behavior.

## Embedded annotations

Room names, objectives, insertion points, destructible surfaces, and any other annotations already
present in Ubisoft's blueprint are part of the background image. They remain visible while editing,
playing, collaborating, sharing, and exporting the strategy.

R6S does not expose these labels as separate overlay switches, and TeamBattles does not infer
objective coordinates from the images. New R6S strategies start without automatically placed player
tokens; add the operators and equipment needed for your plan from the **Tokens** panel.

## Tokens

The R6S catalog has six searchable, collapsible groups:

| Group              | Count |
| ------------------ | ----: |
| Players            |     2 |
| Attackers          |    39 |
| Defenders          |    39 |
| Gadgets            |    14 |
| Generic markers    |     5 |
| Unique abilities   |    76 |
| **Total**          | **175** |

The attacker and defender groups use official operator badges. Gadgets are shared when multiple
operators use the same item, while unique abilities remain tied to their operator. These tokens keep
their authored artwork rather than taking the recolorable player-token palette. The Players and
Generic markers groups reuse TeamBattles' shared recolorable strategy SVGs for neutral callouts.
