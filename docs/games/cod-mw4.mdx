Call of Duty: Modern Warfare 4 supports TeamBattles match creation, challenges, league play, lobby codes, score proof, and disputes. There is no ranked ladder yet, and the [Strategy Editor](https://teambattles.gg/strategy/editor) does not support MW4 maps because no minimap art exists upstream.

## Status

| Feature                     | Status                                |
| --------------------------- | -------------------------------------- |
| Match creation               | Available                             |
| Challenges                   | Available                             |
| Leagues                      | Available                             |
| Strategy editor support      | Not available (no minimap art)        |
| Rank tracking and overlays   | Not available (no ranked ladder yet)  |

<Warning>
	**Activision connection required.** Every player on both the active roster and the bench must
	link an Activision account. This is enforced when a match is created, accepted, challenged, or
	when a roster is updated - an unlinked player on either roster blocks the request.
</Warning>

## Linking Activision

1. Go to **Settings > Connections**
2. Click **Connect** next to Activision
3. Authorize the connection

## Team Size

| Setting           | Value      |
| ------------------ | ---------- |
| Minimum             | 1 player   |
| Maximum             | 18 players |
| Casual (default)    | 6v6        |
| Competitive         | 4v4        |

Pick the exact size when you create or edit the match: the wizard opens on the casual
default and lets you choose any size between the minimum and maximum. Your choice also
caps the active roster, so the lineup and the team size always agree. The Map Pool
control (Competitive or Flex) only decides which maps are available; it never changes
the team size.

## Playlists

- **Core** - standard gameplay with normal health and HUD elements
- **Hardcore** - reduced health, limited HUD, and friendly fire enabled

## Game Modes

MW4 launches with 10 modes, each drawing from the full 12-map pool:

- Search & Destroy
- Hardpoint
- Hijack
- Team Deathmatch
- Domination
- Kill Confirmed
- Free-for-All
- Inflation
- Gunfight
- Gunfight 10v10

<Note>
	Gunfight is 2v2 with preset loadouts. Gunfight 10v10 is a large-scale variant with preset
	loadouts and no respawns until a round ends.
</Note>

## Map Selection

During match creation, choose a preference mode - **Veto** (ban maps) or **Preferred** (pick maps) - across the shared 12-map pool: Silkworm, Coal, Lithium, Cachette, Munition, Transit213, Mumbai, Nautical, Rooftops, Sentry, Reactor U92, and Lotus.

<Note>Maps have cover art only. There are no interactive minimaps or tactical callouts for MW4.</Note>

## What's Not Wired Up Yet

- Strategy editor support (no minimap art upstream)
- Rank tracking and stream overlays (no ranked ladder)
- A few additional game modes, pending icon art
