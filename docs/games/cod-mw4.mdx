Call of Duty: Modern Warfare 4 supports TeamBattles match creation, challenges, league play, lobby codes, score proof, and disputes. There is no ranked ladder yet, and the [Strategy Editor](https://teambattles.gg/strategy/editor) does not support MW4 maps because there is no minimap art for them yet.

## Status

| Feature                     | Status                                |
| --------------------------- | -------------------------------------- |
| Match creation               | Available                             |
| Challenges                   | Available                             |
| Leagues                      | Available                             |
| Strategy editor support      | Not available (no minimap art)        |
| Rank tracking and overlays   | Not available (no ranked ladder yet)  |

<Warning>
	**Activision connection required.** Every player on both the active roster and the bench must
	link an Activision account. This is enforced when a match is created, accepted, challenged, or
	when a roster is updated - an unlinked player on either roster blocks the request.
</Warning>

## Linking Activision

1. Go to **Settings > Connections**
2. Click **Connect** next to Activision
3. Authorize the connection

## Team Size

| Setting           | Value      |
| ------------------ | ---------- |
| Minimum             | 1 player   |
| Maximum             | 18 players |
| Casual (default)    | 6v6        |
| Competitive         | 4v4        |

Pick the exact size when you create or edit the match: the wizard opens on the casual
default and lets you choose any size between the minimum and maximum. Your choice also
caps the active roster, so the lineup and the team size always agree. The Map Pool
control (Competitive or Flex) only decides which maps are available; it never changes
the team size.

## Playlists

- **Core** - standard gameplay with normal health and HUD elements
- **Hardcore** - reduced health, limited HUD, and friendly fire enabled

## Game Modes

MW4 supports 11 modes, and every mode draws from the full 24-map pool. Score limits are the values hosts set in the private match lobby.

| Mode               | Playlists          | Score limit |
| ------------------ | ------------------ | ----------- |
| Search & Destroy   | Core and Hardcore  | 6           |
| Collateral         | Core               | 6           |
| Hardpoint          | Core and Hardcore  | 250         |
| Hijack             | Core and Hardcore  | 300         |
| Team Deathmatch    | Core and Hardcore  | 100         |
| Domination         | Core and Hardcore  | 200         |
| Kill Confirmed     | Core and Hardcore  | 75          |
| Free-for-All       | Core and Hardcore  | 30          |
| Inflation          | Core and Hardcore  | 1           |
| Frontline          | Core               | 100         |
| Gunfight           | Core               | 6           |

<Note>
	Collateral is Search & Destroy with a buy phase: you earn cash each round to buy your loadout, then
	attack or defend two bomb sites with no respawns. Gunfight gives everyone the same preset loadout,
	which changes every two rounds.
</Note>

## Map Selection

During match creation, choose a preference mode - **Veto** (ban maps) or **Preferred** (pick maps) - across the shared 24-map pool:

- **Launch maps:** Silkworm, Coal, Lithium, Cachette, Munition, Transit 213, Mumbai, Nautical, Rooftops, Sentry, Reactor U92, and Lotus
- **Season 1 maps:** Backstab, Canyon, and Shoot House
- **Additional maps:** Cafe, Forest, Imjin Farmland, Library, NYC, Smuggler, Wolves Stadium, Shipment, and Kill Block

<Note>Maps have cover art only. There are no interactive minimaps or tactical callouts for MW4.</Note>

## What's Not Wired Up Yet

- Strategy editor support (no minimap art yet)
- Rank tracking and stream overlays (no ranked ladder)
- Modes outside the table above, such as Gun Game, Proving Grounds, Possession, and Infected
