Call of Duty: Black Ops 6 supports match creation, challenges, leagues, and tournaments, alongside full [Strategy Editor](https://teambattles.gg/strategy/editor) support on every released minimap.

## Requirements

All players on both rosters must have an **Activision** account linked before the match starts. Link yours under Settings, then Connections.

## Team Sizes

| Setting              | Players per side |
| --------------------- | ---------------- |
| Casual (default)     | 6                 |
| Competitive          | 4                 |
| Selectable range     | 1 to 12           |

The match wizard opens on the default and lets you pick any size in the range. The strategy editor always plans at the competitive size, so a new Black Ops 6 board opens with 4 tokens per side.

## Game Modes

Eleven modes are available. The three competitive modes carry curated map pools; the rest draw from the full 40-map roster.

| Mode              | Short | Map pool     |
| ----------------- | ----- | ------------ |
| Hardpoint         | HP    | Competitive  |
| Search & Destroy  | S&D   | Competitive  |
| Control           | CTRL  | Competitive  |
| Domination        | DOM   | Full roster  |
| Team Deathmatch   | TDM   | Full roster  |
| Free-for-All      | FFA   | Full roster  |
| Kill Confirmed    | KC    | Full roster  |
| Kill Order        | KO    | Full roster  |
| Headquarters      | HQ    | Full roster  |
| Gunfight          | GF    | Small maps   |
| Face Off          | FO    | Small maps   |

## Competitive Map Pools

Choosing **Competitive** map selection restricts the pool to the current ranked rotation for the selected mode.

| Mode              | Maps                                                |
| ----------------- | --------------------------------------------------- |
| Search & Destroy  | Dealership, Hacienda, Protocol, Red Card, Rewind    |
| Hardpoint         | Hacienda, Red Card, Rewind, Skyline, Vault          |
| Control           | Hacienda, Protocol, Vault                            |

Choosing **Flex** opens the pool to every released map.

### Small map rotation

Gunfight and Face Off share a 15-map rotation: Babylon, Blitz, Bullet, Eclipse, Exchange, Gala, Heirloom, Jackpot, Lifeline, Nomad, Pit, Racket, Signal, Stakeout, Warhead.

## Playlists

**Core** uses standard health and HUD. **Hardcore** reduces health, limits the HUD, and enables friendly fire. See the [Black Ops 6 rules](https://teambattles.gg/rules/call_of_duty_black_ops_6) for the private match settings each mode requires.

## Rank Tracking

Black Ops 6 has no rank tracking on TeamBattles yet. Match results count toward your team record and experience, but no skill rating is stored or displayed.

## Strategy Editor

All 40 Black Ops 6 maps are drawable, each with a minimap and derived spawn positions.

Babylon, Barrage, Blitz, Bounty, Bullet, Dealership, Derelict, Eclipse, Exchange, Extraction, Firing Range, Fringe, Fugitive, Gala, Grind, Hacienda, Haven, Heirloom, Hideout, Jackpot, Lifeline, Lowtown, Nomad, Payback, Pit, Protocol, Racket, Red Card, Rewind, Runway, Scud, Shutdown, Signal, Skyline, Stakeout, Subsonic, Vault, Vorkuta, Warhead, World Motor Dynasty (WMD).

### Overlay Layers

Black Ops 6 ships six image-overlay layers, toggled independently of the selected mode. Four correspond to a specific objective mode (Domination, Hardpoint, Search and Destroy, Headquarters); the other two (Spawn, Areas) are general-purpose and available regardless of mode:

- Domination zones
- Hardpoint zones
- Search and Destroy zones
- Spawn zones
- Areas
- Headquarters

Marker-based toggles (spawns, POI labels) are not available for Black Ops 6 because the upstream guide data does not ship per-map marker coordinates.
