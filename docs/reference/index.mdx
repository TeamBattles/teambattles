Quick reference for limits and constraints across TeamBattles.

## Character Limits

| Field             | Limit                                           |
| ----------------- | ----------------------------------------------- |
| Username          | 3-30 characters (letters, numbers, underscores) |
| Display Name      | 1-50 characters                                 |
| Bio               | 500 characters max                              |
| Organization Name | 3-50 characters (letters, numbers, spaces)      |
| Organization Tag  | 2-6 characters (uppercase letters, numbers)     |
| Team Tag          | 2-5 characters (uppercase letters, numbers)     |
| Bracket Title     | 120 characters max (Battles Brackets)           |

## File Size Limits

| Type         | Max Size | Max Count       | Notes                            |
| ------------ | -------- | --------------- | -------------------------------- |
| Avatar       | 1 MB     | 1               | Replaces previous                |
| Banner       | 2 MB     | 1               | Replaces previous                |
| Screenshot   | 2 MB     | 10 per match    | For score proof                  |
| Bracket Logo | 1 MB     | 128 per bracket | Battles Brackets entrant avatars |
| Chat Image   | 2 MB     | 10 per team     | Per match chat                   |

Tournament logos and sponsor logos use the avatar limit (1 MB); tournament banners use the banner limit (2 MB).

<Note>
	All uploaded images are automatically scanned for NSFW content. Images flagged as inappropriate
	are rejected before being stored. Avatar, banner and logo limits are enforced on the stored file,
	not only in the browser, and SVG is never accepted.
</Note>

<Note>
	Limits are enforced as soft limits - existing items above the limit are preserved on downgrade,
	but new additions are blocked. Saved-strategy gating is dual-axis: on the Free tier
	`strategiesPerMap` is unlimited and `strategiesTotal` caps you at 3; on paid tiers
	`strategiesTotal` is unlimited and the per-map cap applies. See
	[Subscriptions](/subscriptions) for the full breakdown.
</Note>

## API Key Constraints

| Setting                  | Limit                                |
| ------------------------ | ------------------------------------ |
| Keys per user            | [Varies by tier](#tier-based-limits) |
| Label length             | 1-50 characters                      |
| Key format               | `tb_` prefix + 64 hex characters     |
| Matches per API response | 100 max                              |

API keys carry granular permission scopes (matches, connections, game, users, teams, orgs, billing, tickets, strategies, chat, stream, webhooks) plus optional league and tournament capability allowlists, honored when the key's owner holds the matching standing on the league or tournament in the URL. Responses include `X-RateLimit-Limit`, `X-RateLimit-Remaining`, and `X-RateLimit-Reset` headers (plus `Retry-After` on a `429`). See [Authentication](/developers/authentication) for the full scope vocabulary, error codes, and rate-limit details.

## Tournament API Constraints

| Setting | Constraint |
| --- | --- |
| Path identifier | Tournament **slug** only. A tournament ID answers `404 error_tournament_not_found` |
| Organizer authority floors | ADMIN (17 endpoints) and MANAGER (9). A tournament `MODERATOR` meets MANAGER but not ADMIN |
| Organizer plan gate | `api_pro` on the **tournament host owner's** personal developer plan (`tournamentOrganizerApi`) |
| Platform staff standing | Grants **no** Tournament API authority. Staff act through the web console |
| Discovery page size | 1-50, default 12. `search` is ignored below 2 characters |
| Entry roster array | Max 64 user IDs, and at least the tournament's `teamSize` |
| Idempotency (`POST /tournaments`) | Optional `Idempotency-Key` header, retained 24 hours, matched on raw request bytes |
| Async endpoints | `start` answers `202` before matches exist; `regenerate-matches` reports an upper bound. Poll the bracket |
| Not in v1 | No tournament results, rounds, or match read endpoints |

See the [Tournament API guide](/developers/tournament-api) for the full authority table and billing split.

## OG Image Specifications

Social preview images (Open Graph) for profiles:

| Property       | Value                       |
| -------------- | --------------------------- |
| Dimensions     | 1200 × 630 pixels           |
| Format         | PNG                         |
| Themes         | Dark (default), Light       |
| Cache duration | 1 hour (browser)            |
| Regeneration   | Automatic on profile update |

**Available endpoints:**

| Profile Type | Endpoint                     |
| ------------ | ---------------------------- |
| User         | `/og/profile/{username}.png` |
| Team         | `/og/team/{slug}.png`        |
| Organization | `/og/org/{slug}.png`         |
