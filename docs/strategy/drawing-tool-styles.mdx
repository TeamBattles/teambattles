---
title: "Drawing styles"
description: "Set the color, thickness, fill, and line ends for every drawing tool"
---

Every drawing tool in the strategy editor - pen, line, arrow, rectangle, ellipse, and polygon -
shares the same style controls. Select any shape you have drawn and the **Properties** panel shows
the options that apply to it.

## Line

Every shape has a line around it. You can set:

- **Color** - pick one, or paste in a hex code such as `#22D3EE`
- **Opacity** - from invisible to solid
- **Thickness** - from 1 (hairline) to 12 (heavy)
- **Style** - solid, dashed, or dotted
- **On or off** - turn the line off entirely

Dashes and dots scale with the thickness, so they look right at any weight.

## Fill

Rectangles, ellipses, and polygons can be filled in as well as outlined. The fill has its own color,
its own opacity (25% to begin with), and its own on/off switch.

<Note>
	A shape has to stay visible somehow. Turn off the last thing that was showing - the line when the
	fill is already off, say - and the other one comes back on, with a note telling you.
</Note>

## Line ends

The pen, line, and arrow tools can have a marker at each end. Both ends are set separately, so you
can have an arrowhead at one end and a dot at the other.

| End            | What it looks like              |
| -------------- | ------------------------------- |
| None           | Nothing                         |
| Arrow (filled) | A solid arrowhead               |
| Arrow (open)   | A hollow V                      |
| Circle         | A solid dot                     |
| Ring           | A hollow circle                 |
| Square         | A solid square                  |
| Diamond        | A solid diamond                 |
| Bar            | A short line across the end     |

Markers scale with the line thickness and turn to follow the direction of the line. Arrows start out
with a filled arrowhead at the finishing end; the pen and line start with nothing on either end.

## Each tool remembers what you used last

Set a rectangle to a red dashed line and the next rectangle you draw comes out the same way, so you
are not setting it up again every time.

<Note>
	Each tool remembers separately - changing your rectangle does not change your ellipse. Everything
	goes back to the starting settings when you reload the page or open a different strategy.
</Note>
