---
title: "Keyboard shortcuts"
description: "The shortcuts built into the strategy editor, and how to change them"
---

Every tool and edit action in the strategy editor has a keyboard shortcut. If you are signed in, you
can change any of them.

## The defaults

| Action          | Shortcut            |
| --------------- | ------------------- |
| Select tool     | `V`                 |
| Pen             | `P`                 |
| Line            | `L`                 |
| Arrow           | `A`                 |
| Rectangle       | `R`                 |
| Ellipse         | `O`                 |
| Polygon         | `G`                 |
| Text            | `T`                 |
| Token           | `K`                 |
| Undo            | `Mod + Z`           |
| Redo            | `Mod + Shift + Z`   |
| Copy            | `Mod + C`           |
| Paste           | `Mod + V`           |
| Duplicate       | `Mod + D`           |
| Delete          | `Delete`            |
| Add stage       | `Mod + Enter`       |
| Next stage      | `Mod + Right Arrow` |
| Previous stage  | `Mod + Left Arrow`  |
| Play and pause  | `Space`             |
| Zoom in         | `Mod + =`           |
| Zoom out        | `Mod + -`           |
| Reset zoom      | `Mod + 0`           |

`Mod` means `Cmd` on a Mac and `Ctrl` on Windows and Linux.

## Change them

You need to be signed in.

<Steps>
	<Step title="Open the shortcuts dialog">Select the gear icon in the editor header.</Step>
	<Step title="Choose what to change">Select the row for the action you want.</Step>
	<Step title="Press your new shortcut">Or press `Esc` to leave it as it was.</Step>
	<Step title="Deal with clashes">
		If something else already uses that combination, you are asked whether to take it over.
	</Step>
	<Step title="Save">
		Select **Save**. Your changes follow you to any device you sign in on.
	</Step>
</Steps>

Each row has a reset icon that puts that one shortcut back to the default, and
**Reset all to defaults** clears everything you have changed.

<Note>
	`Esc` (cancel what you are doing) and `Enter` (finish a polygon) are fixed and cannot be changed.
</Note>
