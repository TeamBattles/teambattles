title: "Troubleshooting"
description: "Fixes for the problems that come up most with Battles Overlay"
---

## The overlay is blank

Your stream shows nothing where the overlay should be.

1. **Check the link.** Copy it again from the editor's Go Live step. It should look like
   `https://teambattles.gg/overlay/render/your-overlay-id`.
2. **Check your profile visibility.** Widgets showing your own data stay empty while your profile is
   set to Private. Change it in [Settings](https://teambattles.gg/settings), or see
   [Visibility and Privacy](/tools/battles-overlay/visibility).
3. **Add the transparency setting.** In your browser source properties, put this in the
   **Custom CSS** box:

```css
body {
	background: transparent;
}
```

4. **Update your streaming software.** Older versions of OBS Studio can struggle with newer web
   pages.

## One widget is missing

The rest of the overlay works, but one widget is not there.

1. **Check it is turned on** in the editor's Widgets step.
2. **Check whose data it shows.** Team Stats needs that team to be public, Org Stats needs that
   organization to be public, and anything showing your own data needs your profile to not be
   Private. The editor warns you about this on the Widgets step. See
   [Visibility and Privacy](/tools/battles-overlay/visibility).
3. **Check you picked a team or organization.** Team Stats and Org Stats need one selected in the
   picker beneath their switch.

## The numbers are out of date

1. **Check the refresh setting.** Sixty seconds is the default; you can go as low as 30 in the Go
   Live step.
2. **Check your internet connection.** The overlay needs one to pull in new stats.
3. **Reload the source.** In OBS, right-click the browser source and choose
   **Refresh cache of current page**.

## The overlay has a solid background

Add this to the **Custom CSS** box in your browser source properties:

```css
body {
	background: transparent;
}
```

Also check **Background opacity** in the editor's Style step. Somewhere between 70% and 85% usually
reads well over gameplay.

## The overlay is too big or too small

1. **Use the Size slider** in the editor's Style step to scale every widget at once.
2. **Check the source size.** Set the browser source to `1920` wide by `1080` high. Other sizes can
   make things look stretched.
3. **Resize it in OBS.** Right-click the source and use **Transform > Edit Transform** for finer
   control.

## The Active Match widget never appears

<Note>
	This widget hides itself when you have no match on. That is normal - it comes back when one
	starts.
</Note>

If you do have a match on:

1. **Check your profile visibility.** It must not be set to Private.
2. **Give it a minute.** The widget picks the match up on the next refresh, so wait out your refresh
   interval.
3. **Check the match itself.** It has to be scheduled or in progress, not finished or cancelled.

## The OBS Dock will not connect to OBS

### The connection is switched off

OBS does not enable it by default.

1. In OBS Studio, open **Tools > WebSocket Server Settings**
2. Tick **Enable WebSocket Server**
3. Select **Apply**
4. Try connecting from the dock again

### The port is different

The usual port is `4455`, but it can be changed.

1. In OBS, open **Tools > WebSocket Server Settings**
2. Select **Show Connect Info** to see the port in use
3. Enter that port in the dock before connecting

### It is asking for a password

1. In OBS, open **Tools > WebSocket Server Settings**
2. Select **Show Connect Info** to reveal the password
3. Enter it when the dock asks

### Your firewall is in the way

This is rare, but antivirus or firewall software can block the connection between the dock and OBS
on your own machine.

1. Allow connections to `127.0.0.1` on the port OBS is using
2. Turn the firewall off briefly to confirm that is the cause
3. If it is, add an exception for OBS Studio rather than leaving it off
