This guide takes you from an empty editor to a working overlay on your stream. Your overlay link is
public and holds no password, so all you need to move it into your streaming software is the link
itself.

## Before you start

- A [TeamBattles](https://teambattles.gg) account
- [OBS Studio](https://obsproject.com/) or another streaming app that can add a web page as a source
- A profile that is not set to Private, so your stats can appear. See
  [Visibility and Privacy](/tools/battles-overlay/visibility).

## Build and add your overlay

<Steps>
	<Step title="Open the editor">
		Go to [teambattles.gg/overlay/editor](https://teambattles.gg/overlay/editor). You get a live
		preview of your stream next to four steps: **Widgets**, **Style**, **Arrange**, and **Go Live**.
		Later steps unlock as your overlay takes shape, and you sign in when you are ready to save.
	</Step>
	<Step title="Step 1 - Widgets">
		Turn on the widgets you want from the **TeamBattles** and **Game ranks** groups. Choosing Team
		Stats or Org Stats opens a picker underneath so you can say which team or organization to show.

    	The [Widgets](/tools/battles-overlay/widgets) page describes each one.
    </Step>
    <Step title="Step 2 - Style">
    	Set the look of the whole overlay:

    	- **Theme** - light or dark
    	- **Layout** - Rounded, Angular, or Minimal, with the option to give individual widgets their own
    	- **Colors** - an accent color, plus text, border, and background if you want them
    	- **Transparency** and **Size**
    </Step>
    <Step title="Step 3 - Arrange">
    	Drag widgets around the preview until they sit where you want them:

    	- **Click** a widget to select it, then **drag** it into place
    	- Turn on **Grid** for alignment lines
    	- Turn on **Snap** so widgets line up with each other and with the centre of the screen
    	- On a free account, choose which widget carries the teambattles.gg watermark
    </Step>
    <Step title="Step 4 - Go Live">
    	Name your overlay, choose how often it should refresh (every 30 to 300 seconds), and select
    	**Save**. You need to be signed in, and you can keep up to five overlays. Your link then appears
    	with a copy button.

    	<Tip>
    		Go Live also gives you a separate link for each widget, so you can place them individually in
    		your streaming software instead of as one full-screen layer.
    	</Tip>
    </Step>
    <Step title="Add it to OBS">
    	In OBS Studio:

    	1. Select **+** in the **Sources** panel
    	2. Choose **Browser**
    	3. Name it something like "Battles Overlay"
    	4. Paste your overlay link
    	5. Set **Width** to `1920` and **Height** to `1080`, and leave **FPS** at `30`
    	6. In the **Custom CSS** box, enter:

    	```css
    	body { background: transparent; }
    	```

    	7. Select **OK**
    </Step>

</Steps>

## Other streaming software

<AccordionGroup>
	<Accordion title="Streamlabs Desktop">
		1. Select **+** in the **Sources** panel
		2. Choose **Browser Source**
		3. Name it something like "Battles Overlay"
		4. Paste your overlay link into the **URL** box
		5. Set **Width** to `1920` and **Height** to `1080`
		6. Make sure **Custom CSS** contains:

    	```css
    	body { background: transparent; }
    	```

    	7. Select **Done**

    	<Tip>
    		Streamlabs Desktop is built on OBS, so everything behaves the same way.
    	</Tip>
    </Accordion>
    <Accordion title="XSplit Broadcaster">
    	1. Select **Add Source** in the scene editor
    	2. Choose **Webpage URL**
    	3. Paste your overlay link
    	4. Set the size to `1920 x 1080`
    	5. Turn on the **Transparent** background option if you see one
    </Accordion>
    <Accordion title="Meld Studio">
    	1. Select **+** in the **Scene Layers** sidebar
    	2. Choose **Browser**
    	3. Paste your overlay link
    	4. Set the size to `1920 x 1080`
    </Accordion>
    <Accordion title="Prism Live Studio">
    	1. Select **Add Source**
    	2. Choose **Browser**
    	3. Paste your overlay link
    	4. Set the size to `1920 x 1080`
    </Accordion>
    <Accordion title="TikTok LIVE Studio">
    	1. Select **+** beside **Sources**
    	2. Choose **Link**
    	3. Paste your overlay link
    	4. Drag it to the size and position you want
    </Accordion>

</AccordionGroup>

## Tips

<Tip>
	**How often it refreshes.** Sixty seconds suits most streams. Drop it to 30 in the Go Live step if
	you want scores to move faster during a match.
</Tip>

<Tip>
	**Fine-tuning in OBS.** Once the source is added, you can still move and resize it in OBS. The
	overlay is designed for a 1920 x 1080 screen but scales to others.
</Tip>

<Note>
	Widgets showing your own stats stay empty while your profile is set to Private, and team or
	organization widgets stay empty while that team or organization is private. See
	[Visibility and Privacy](/tools/battles-overlay/visibility).
</Note>
