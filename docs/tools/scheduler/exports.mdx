Everything here is made on your own computer. Your roster and schedule are never uploaded.

## Share the lineups

| Option                          | What you get                                                          |
| ------------------------------- | --------------------------------------------------------------------- |
| **Copy list of names**          | The starters and every substitute for one match.                      |
| **Copy all name lists**         | Every match in one block of text, in order.                           |
| **Download lineup card image**  | A ready-to-post image for one match.                                  |
| **All lineup cards (one file)** | One image with every match on it. Matches without a lineup are left out. |
| **Board overview image**        | A picture of your whole schedule, available even before your first run. |

Copying names and downloading cards become available once at least one match has a lineup, whether
built for you or made by hand. They wait while an animated run is still playing.

### One match

Use a single lineup card when you only need to post one match. It shows the starters, the
substitutes, how many are starting, the start time, and who is on Host and IGL.

![An exported Battles Scheduler lineup card for one match time with six starters, five substitutes, and assigned Host and IGL duties](../../images/scheduler/scheduler-lineup-card.png)

You can save images as PNG, JPEG, or WebP, at normal, double, or triple size. If the size you asked
for is more than your browser can draw, Battles Scheduler drops it down a step. If a combined image
is still too big, save each match on its own instead.

<Note>
	An out-of-date lineup can still be shared. Images get a marker saying so, and copied names match
	what is on the board right now.
</Note>

### Every match in one image

**All lineup cards (one file)** puts every match into a single image, each in its own card, in
order.

![A combined Battles Scheduler export showing lineup cards for six match times](../../images/scheduler/scheduler-lineup-cards.png)

### The whole board

The board overview turns your entire schedule into one picture, so it can travel as a single image.

![A Battles Scheduler board overview with six match times, starters, and substitutes](../../images/scheduler/scheduler-board-overview.png)

### How the images look

Every image carries the TeamBattles look - the honeycomb background and the TeamBattles logo.
Whole-schedule images also get a colored bar across the top and your schedule's name.

Colors follow whatever TeamBattles looks like to you, so an image matches the site you are looking
at. Signed in, the theme and accent color from [Appearance settings](../../settings/appearance)
carry into everything you save.

<Note>
	Times in an image always name their time zone, even when the app itself does not show one because
	the whole schedule is in a single zone. It keeps a card unambiguous for whoever you send it to.
</Note>

## Keep a backup

Schedules live in this browser only. Download a schedule file when you want to:

- Keep a schedule safe before clearing your browser data
- Move it to another browser or another computer
- Hold on to a copy outside TeamBattles
- Use one schedule as the starting point for the next

**Export .tbsched** is available from both the schedule list and the editor. Opening a file back up
creates a normal schedule, and lets you choose which parts to bring across.

<Warning>
	Your work is saved as you go, but that is not a backup. Clearing this site's data deletes every
	schedule in this browser.
</Warning>

## Limits

| Item                    | Limit                                                     |
| ----------------------- | --------------------------------------------------------- |
| Players                 | 64 per schedule                                           |
| Match times             | 64 per schedule                                           |
| Together/apart pairings | 512 per schedule                                          |
| Players per match       | 1 to 32; 6 to begin with                                  |
| Minimum gap             | 0 to 720 minutes; 30 to begin with                        |
| Schedule file size      | 8 MB                                                      |
| Undo steps              | Up to 50, or at least 5 on very large schedules           |

## Troubleshooting

### My schedule is gone

Schedules only exist in the browser you made them in. If that browser's data was cleared, open your
backup file to get the schedule back.

### I cannot edit anything

You need a laptop or desktop screen. If another tab has the schedule open, select **Take over**. If
that does nothing, close the other tab and try again.

### Copying names or saving a card is greyed out

Wait for the animated run to finish. If you have not built any lineups yet, run it or place players
by hand first.

### The combined image will not save

Save the matches individually, or pick a smaller image size. If JPEG or WebP fails, try PNG.

### A schedule file will not open

Check that it came from Battles Scheduler, is under 8 MB, and was made by a compatible version.

For anything to do with your browser or your account, see
[Troubleshooting](../../reference/troubleshooting).
