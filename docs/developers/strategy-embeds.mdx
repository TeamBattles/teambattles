---
title: Strategy Embeds
description: Embed a shared Battles Strategy board in a page as an iframe, and drive its playback with postMessage.
---

Any shared [strategy](/strategy/managing-strategies) can be embedded in a web page as an iframe.
The embed accepts query parameters for its initial state, and a `playback:*` postMessage protocol
for runtime control.

Streamers and coaches who only want the embed code do not need this page - the strategy editor's
share dialog hands you a ready-made snippet.

## Quick start

```html
<iframe
	src="https://teambattles.gg/strategy/embed/<shareSlug>?autoplay=1&loop=1"
	width="600"
	height="600"
	frameborder="0"
></iframe>
```

## URL parameters

| Parameter  | Default     | Description                                           |
| ---------- | ----------- | ----------------------------------------------------- |
| `autoplay` | `1`         | Start playback on mount (`0` or `1`).                 |
| `loop`     | `1`         | Loop back to the first stage at the end (`0` or `1`). |
| `controls` | `0`         | Show the Play/Stop button (`0` or `1`).               |
| `chips`    | `0`         | Show stage chips (`0` or `1`).                        |
| `start`    | first stage | Stage id or 1-based index to start on.                |
| `speed`    | `1`         | Playback multiplier, clamped to `[0.25, 4.0]`.        |
| `branding` | `1`         | Show the "Powered by TeamBattles" link (`0` or `1`).  |

Stage selection remains authoritative for map levels. If a selected stage has no `levelId`, the
embed uses the built-in map's default level. There is no level URL parameter or level-specific
postMessage command; use `playback:goto` to select a stage.

## postMessage API

Send messages to the iframe with `iframe.contentWindow.postMessage({ type, ... }, "*")`:

| Type                | Payload                        | Effect                                     |
| ------------------- | ------------------------------ | ------------------------------------------ |
| `playback:play`     | -                              | Start playback if paused.                  |
| `playback:pause`    | -                              | Stop the in-flight tween.                  |
| `playback:toggle`   | -                              | Flip play/pause.                           |
| `playback:goto`     | `{ stageId? }` or `{ index? }` | Switch to a stage.                         |
| `playback:setSpeed` | `{ value: number }`            | Update speed multiplier (next transition). |
| `playback:setLoop`  | `{ value: boolean }`           | Update loop setting.                       |

The iframe broadcasts back on every transition and on play/pause:

```json
{ "type": "playback:state", "isPlaying": true, "currentStageId": "stg_1", "currentStageIndex": 0 }
```

## Example: external Play button

```html
<button
	onclick="document.getElementById('strategy').contentWindow.postMessage({ type: 'playback:toggle' }, '*')"
>
	Play / Pause
</button>
<iframe id="strategy" src="https://teambattles.gg/strategy/embed/abc?controls=0"></iframe>
```

<Note>
	A strategy built on a [custom map](/strategy/custom-maps) only shows that map for its owner, so an
	embed of one appears without its background to everyone else.
</Note>
