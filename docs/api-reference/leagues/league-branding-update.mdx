---
title: "Update League Branding"
description: "Update a league's public profile branding and metadata."
openapi: "POST /leagues/{identifier}/branding/update"
---

## Permission Required

This endpoint requires a personal or developer API key whose owner is currently a league **ADMIN** of the league in the path, with the `branding` capability set to `write` on the key. League API access is gated at api_pro on the **league owner's** plan.

## Membership Required

The API key owner must have an **ADMIN or higher** role in the league, or be a TeamBattles staff member.

## League Identifier

The `{identifier}` path parameter accepts a league slug or Convex league ID.

## Behavior

Branding updates can change the league name, description, social links, profile theme, avatar storage ID, and banner storage ID. The league name remains globally unique after normalization, and name and description lengths are validated before any write is saved.

`avatarStorageId` and `bannerStorageId` must come from [`POST /uploads/image`](../uploads/upload-bound-image), which records the API key owner as the uploader. A storage ID from `POST /uploads/image-url` - or one belonging to another tenant - is rejected with `400 error_image_blob_unbound` and nothing is written. Avatars are capped at 1 MB and banners at 2 MB.

When avatar or banner storage IDs are replaced, the previous stored asset is queued for removal and deleted by a daily reclaim job rather than immediately.
