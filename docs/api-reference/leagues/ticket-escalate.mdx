---
title: "Escalate League Ticket"
description: "Escalate a league support ticket to TeamBattles staff."
openapi: "POST /leagues/{identifier}/tickets/{ticketId}/escalate"
---

## Permission Required

This endpoint requires a personal or developer API key whose owner is currently a league **ADMIN** of the league in the path, with the `tickets` capability set to `write` on the key. League API access is gated at api_pro on the **league owner's** plan.

## Membership Required

The API key owner must have a **MANAGER or higher** role in the league, or be a TeamBattles staff member.

## League Identifier

The `{identifier}` path parameter accepts a league slug or Convex league ID.

## Ticket ID

The `{ticketId}` path parameter is the league ticket to escalate.

## Behavior

Escalating a ticket marks it as escalated, records the escalation reason, adds a system message, and notifies league staff plus the original ticket creator when they are not already included.
