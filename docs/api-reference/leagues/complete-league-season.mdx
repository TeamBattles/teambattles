---
title: "Complete A League Season"
description: "Mark an active league season as complete."
openapi: "POST /leagues/{identifier}/seasons/{seasonId}/complete"
---

## Permission Required

This endpoint requires a personal or developer API key whose owner is currently a league **ADMIN** of the league in the path, with the `seasons` league capability set to `write` on the key. League API access is gated at api_pro on the **league owner's** plan; when the owner's plan lacks it, the request receives `403 error_api_feature_required`.

## Access / Membership Rules

You must have a **MANAGER or higher** role in the league (or be a TeamBattles staff member) to complete seasons. If you lack the required access, you'll receive a `403` error.

The `{identifier}` path parameter is the league **slug** - the URL-friendly league name (e.g., `my-league`). The `{seasonId}` path parameter is the league season ID to complete.

## What's Returned

Completes an active league season. On success the response is `{ "success": true, "timestamp": "<ISO 8601>" }`.

<Note>
	Replays are not deduped. A state guard returns the current state error if the season is no longer active.
</Note>

<RequestExample>

```bash cURL
curl -X POST https://teambattles.gg/api/v1/leagues/my-league/seasons/js5season789/complete \
  -H "Authorization: Bearer tb_your_api_key"
```

```javascript JavaScript
const leagueSlug = "my-league";
const seasonId = "js5season789";

const response = await fetch(
	`https://teambattles.gg/api/v1/leagues/${leagueSlug}/seasons/${seasonId}/complete`,
	{
		method: "POST",
		headers: {
			Authorization: "Bearer tb_your_api_key"
		}
	}
);

const { success, timestamp } = await response.json();
console.log(success, timestamp);
```

```python Python
import requests

league_slug = 'my-league'
season_id = 'js5season789'

response = requests.post(
    f'https://teambattles.gg/api/v1/leagues/{league_slug}/seasons/{season_id}/complete',
    headers={'Authorization': 'Bearer tb_your_api_key'}
)

print(response.json())
```
